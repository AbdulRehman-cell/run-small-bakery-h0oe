# Golden Crust Bakery

React + Vite front end with a Supabase (PostgreSQL) backend — generated by ForgeAI.

## Run locally

```bash
npm install
npm run dev
```

The Supabase URL and anon key live in `.env.local` (see `.env.example`). The anon
key is safe in the browser: every table has row-level security enabled.

## Database

- **menu_items** — any visitor can read, create, update and delete rows (no sign-in needed): name, category, description, price_pkr, image_url, is_available, is_featured
- **pickup_orders** — any visitor can read, create, update and delete rows (no sign-in needed): customer_name, phone_number, pickup_time, order_items, total_price_pkr, status, special_notes
